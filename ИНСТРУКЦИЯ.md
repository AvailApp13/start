# Инструкция по добавлению фотографий в галерею

## Структура папок

assets/projects/
  fundament/      <- загружайте фото сюда (фундаменты)
  kladka/         <- загружайте фото сюда (кладка)
  krovlya/        <- загружайте фото сюда (кровля)
  otdelka/        <- загружайте фото сюда (отделка)
  zabory/         <- загружайте фото сюда (заборы)
  fundament.json  <- редактируйте этот файл
  kladka.json
  krovlya.json
  otdelka.json
  zabory.json

## Как добавить фотографии (2 шага)

### Шаг 1: Загрузите фото

Откройте папку нужного раздела в GitHub.
Нажмите Add file -> Upload files.
Загрузите JPG/PNG/WebP файлы.

### Шаг 2: Обновите JSON-манифест

Откройте файл assets/projects/<раздел>.json и добавьте имена файлов.

Простой вариант (только имена):
{
  "images": [
    "photo1.jpg",
    "photo2.jpg",
    "photo3.jpg"
  ]
}

Расширенный вариант (с описаниями):
{
  "images": [
    {
      "file": "photo1.jpg",
      "title": "Монолитный фундамент",
      "desc": "Монолитная плита 12x8м, 2024",
      "tags": ["monolith"],
      "size": "large"
    }
  ]
}

Параметры: file (обязательно), title, desc, tags, size (large/medium/small)

## Теги по разделам

fundament: monolith, strip, pile
kladka: brick, block, stone
krovlya: flat, pitched, repair
otdelka: interior, facade, floor
zabory: metal, brick, landscape

## Готово

После сохранения JSON Vercel автоматически задеплоит изменения.
Сайт покажет фото с фильтрами, анимациями и лайтбоксом.
Редактировать HTML или JS не нужно.
