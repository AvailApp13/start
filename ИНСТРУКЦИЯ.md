# Инструкция: как добавлять фото проектов

## Структура папок

```
ваш-сайт/
├── index.html                    ← Главная страница
├── pages/
│   ├── fundament.html            ← Страница "Фундаменты"
│   ├── kladka.html               ← Страница "Кладка"
│   ├── krovlya.html              ← Страница "Кровля"
│   ├── otdelka.html              ← Страница "Отделка"
│   └── zabory.html               ← Страница "Заборы"
├── assets/
│   └── projects/
│       ├── fundament/            ← Сюда кладёте фото фундаментов
│       ├── kladka/               ← Сюда фото кладки
│       ├── krovlya/              ← Сюда фото кровли
│       ├── otdelka/              ← Сюда фото отделки
│       └── zabory/               ← Сюда фото заборов
├── portfolio.css                 ← Стили галереи
└── portfolio.js                  ← Логика галереи
```

## Как добавить фото

### Шаг 1 — Подготовьте фото

Рекомендуемые параметры:
- Формат: **JPG** (не PNG — тяжелее)
- Ширина: **1200–1600px** (не больше)
- Сжатие: используйте [squoosh.app](https://squoosh.app) или [tinyjpeg.com](https://tinyjpeg.com)
- Качество: **80–85%** — хорошее качество при малом весе

### Шаг 2 — Назовите файлы правильно

Только латиница, цифры, дефис. **Без пробелов, без кириллицы.**

✅ Правильно: `foto-01.jpg`, `monolith-spb-2024.jpg`  
❌ Неправильно: `фото 1.jpg`, `Монолит СПБ.JPG`

### Шаг 3 — Положите фото в нужную папку

| Раздел | Папка |
|--------|-------|
| Фундаменты | `assets/projects/fundament/` |
| Кладка | `assets/projects/kladka/` |
| Кровля | `assets/projects/krovlya/` |
| Отделка | `assets/projects/otdelka/` |
| Заборы | `assets/projects/zabory/` |

### Шаг 4 — Добавьте фото в файл страницы

Откройте файл нужной страницы, например `pages/fundament.html`.

Найдите в конце файла блок `window.PORTFOLIO_CONFIG = { ... }`.

Добавьте объект в массив `projects`:

```javascript
projects: [
  {
    src: '../assets/projects/fundament/foto-01.jpg',  // путь к файлу
    title: 'Монолитная плита, ул. Лазо',              // заголовок
    desc: 'Плита 10×8м, армирование, гидроизоляция',  // описание
    tags: ['monolith'],                                // тег фильтра
    size: 'large'                                      // размер карточки
  },
  {
    src: '../assets/projects/fundament/foto-02.jpg',
    title: 'Ленточный фундамент',
    desc: '2024 год, Надежда',
    tags: ['strip'],
    size: 'medium'
  },
]
```

### Размеры карточек (`size`)

| Значение | Пропорции | Когда использовать |
|----------|-----------|-------------------|
| `large`  | 4:3       | Горизонтальные фото, главные объекты |
| `medium` | 1:1       | Квадратные фото |
| `small`  | 3:2       | Детальные снимки |

Чередуйте `large`, `medium`, `small` для красивого masonry-эффекта.

### Теги для фильтров

#### Фундаменты (`fundament.html`)
- `monolith` — монолитный
- `strip` — ленточный
- `pile` — свайный

#### Кладка (`kladka.html`)
- `block` — блок
- `brick` — кирпич
- `partition` — перегородки

#### Кровля (`krovlya.html`)
- `metal` — металлочерепица
- `soft` — гибкая кровля
- `facade` — фасад

#### Отделка (`otdelka.html`)
- `rough` — черновая
- `finish` — чистовая
- `exterior` — наружная

#### Заборы (`zabory.html`)
- `profnastil` — профнастил
- `brick` — кирпич
- `gates` — ворота/калитки

## Пример: добавление 3 фото в "Фундаменты"

1. Сохраните фото как: `foto-01.jpg`, `foto-02.jpg`, `foto-03.jpg`
2. Скопируйте в папку: `assets/projects/fundament/`
3. Откройте `pages/fundament.html`
4. Найдите `projects: [` и вставьте:

```javascript
projects: [
  {
    src: '../assets/projects/fundament/foto-01.jpg',
    title: 'Монолитный фундамент, частный дом',
    desc: 'Плита 200мм, армирование д12, гидроизоляция Технониколь',
    tags: ['monolith'],
    size: 'large'
  },
  {
    src: '../assets/projects/fundament/foto-02.jpg',
    title: 'Ленточный фундамент под гараж',
    desc: 'Заглубление 1.5м, ширина 400мм',
    tags: ['strip'],
    size: 'medium'
  },
  {
    src: '../assets/projects/fundament/foto-03.jpg',
    title: 'Армирование плиты',
    desc: 'Процесс работы',
    tags: ['monolith'],
    size: 'small'
  },
]
```

5. Сохраните файл и загрузите на сервер.

## Деплой на Vercel

Файл `vercel.json` уже настроен. Просто:

1. Загрузите все файлы в репозиторий GitHub
2. Подключите репозиторий к Vercel
3. Деплой произойдёт автоматически

## Часто задаваемые вопросы

**Можно ли добавить тег без фильтра?**  
Да, оставьте `tags: []` — фото будет только в "Все работы".

**Что если фото тяжёлые и грузятся долго?**  
Используйте [squoosh.app](https://squoosh.app) — сожмите до 80KB–200KB. Lazy loading уже включён.

**Сколько фото добавлять?**  
5–20 на раздел — оптимально. Меньше — пусто, больше — долго грузится.
